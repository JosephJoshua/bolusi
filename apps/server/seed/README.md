# Phone catalog seed

`phone-catalog.ndjson.gz` holds the phone catalog's brands, models, model codes and
specs (no photos), one JSON object per line, in the format
`apps/server/src/catalog/catalog-file.ts` reads. Load it into the dev database with
`pnpm db:seed-catalog`, or into any database with
`DATABASE_URL=<owner url> pnpm --filter @bolusi/server load-phone-catalog seed/phone-catalog.ndjson.gz`.

The photos are kept privately, not in this repository: they are copyrighted by their
publishers (mostly GSMArena). Load the private photo file the same way.
